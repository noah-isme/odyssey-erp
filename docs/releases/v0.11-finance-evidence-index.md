**Status:** preparation evidence template; this record does not certify staging or production

**Candidate commit:** UNVERIFIED — populate only after publishing the candidate
**Last reviewed:** 2026-08-29

This index is the controlled handoff for the isolated finance sandbox. Every row
must point to an immutable evidence object (or explicitly explain why the proof is
`N/A`) and must include its SHA-256, collection time, owner, and reviewer. A local
unit test, source inspection, or successful build is not staging evidence unless
the row's required proof says that it is the applicable scope.

Do not replace `UNVERIFIED` with `PASS` until the named command or scenario has
run against the recorded candidate and the referenced artifact has been retained.
Provider credentials, database identities, tenant fixtures, and approval names
are intentionally absent from this template.

## Collection commands

Run the local structural checks before publishing a candidate:

```bash
RELEASE_PROFILE=v0.11-finance make finance-sandbox-check
```

The sandbox workflow generates and verifies `ROUTE_PROFILE.json`, migration and
web manifests, `SHA256SUMS`, `BUNDLE_SHA256SUMS`, the SPDX SBOM, and the GitHub
build-provenance attestation. Preserve the workflow summary and downloaded
artifacts together with this index; do not copy a digest from a different run.

For a completed evidence review, run the strict gate after all rows have been
collected and reviewed:

```bash
bash scripts/check-finance-sandbox-handoff.sh --require-complete
```

The strict gate is expected to fail for this template. That failure is intentional
until the external sandbox, provider, database, rollback, and approval evidence is
available.

## Findings and decision

Record each finding with an owner, severity, evidence ID, disposition, and due
date in the review system referenced by `APR-011`. Do not mark the v0.11 matrix
row `production-certified=yes` or enable live provider execution while any
required registry row is `UNVERIFIED` or `FAIL`.

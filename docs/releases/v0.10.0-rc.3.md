# Odyssey ERP v0.10.0-rc.3 — 2026-08-10

**Status:** Release candidate; not production-certified.

This candidate supersedes `v0.10.0-rc.2` by making self-managed VPS deployment
the only documented production target and removing the obsolete hosted blueprint.

## Changes since rc.2

- Removed the obsolete Render configuration, deployment guide, and blueprint test.
- Updated the release gate to verify the VPS runbook instead of a hosted-provider
  plan.
- Updated the README, release checklist, and feature matrix to identify the
  self-managed VPS target and its required systemd/Nginx, backup, health, and
  rollback evidence.
- Preserved capability statuses as evidence-based values; VPS hosting does not
  certify incomplete workflows or provider/staging integrations.

## Verification

- `make release-check` passes.
- The repository contains no active hosted-blueprint configuration or references.
- The release gate is tagged and verifies the VPS deployment runbook.

## Remaining promotion gates

- Feature rows remain non-certified where their implementation, integration, or
  staging/provider evidence is partial or absent.
- Complete the VPS backup/restore, TLS, monitoring, smoke, and rollback evidence
  before production promotion.
- Complete official tax, provider, migration, security, and operational evidence
  listed in the production release checklist.

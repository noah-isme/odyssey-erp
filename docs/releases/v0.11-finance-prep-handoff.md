**Status:** preparation candidate only; working tree has uncommitted prep changes; not a release tag and not production-certified

This is the bounded handoff for the Treasury + P2P work that follows the immutable
`v0.10.0-rc.7` core line. It must remain separate from the rc.7 promotion record and
must use the isolated finance sandbox. Asset locations, custody/transfers,
warranty/maintenance extensions, and capitalization remain outside this first tranche.

The recorded commit is the clean preparation baseline. The current isolated working
tree adds provider-router fail-closed behavior, worker AP dependency wiring, exact
goods-return quantity checks, settlement-result consistency checks, company-scoped
PO/GRN workbench reads and PR/PO/GRN detail/transition guards, tenant propagation for
new GRNs, an AP exception workbench with tenant/RBAC guards, and immutable resolution
events in migration `000129`; publish
a new commit and regenerate the candidate identity before dispatching the sandbox
workflow.

## Local implementation updates

- [x] Bank-feed sync, statement-transport, and webhook paths resolve through an
      explicit provider router and fail closed before creating durable records when
      no approved adapter is registered.
- [x] Bank-feed worker tasks reject missing services, nil tasks, and invalid
      connection/event identifiers with non-retryable errors; the profile-gated
      scheduler remains provider-fail-closed until an approved adapter is configured.
- [x] Bank-feed polling and statement transport take a per-connection PostgreSQL
      advisory lease; sync and callback task enqueuers carry only scoped IDs,
      fail closed when the queue client is unavailable, and collapse duplicate
      queued work by task ID.
- [x] The provider router rejects normalized-name collisions instead of allowing
      map iteration order to choose an adapter; invalid registration fails closed.
- [x] The finance-sandbox workflow requires an explicit candidate ref, pinned SSH
      host keys, a digest-addressed release bundle, and remote commit/ref/revision
      plus migration-ceiling verification before restart.
- [x] Worker AP processing validates and wires accounting, tax, and FX boundaries;
      the finance-sandbox Iris adapter rejects production credentials/endpoints before
      network I/O, and settlement effects remain explicitly fail closed when unsupported.
- [x] Goods-return cumulative quantity checks use the schema's exact four-decimal
      domain and reject non-finite legacy float inputs.
- [x] Goods-receipt intake rejects supplier/product/line-shape violations and
      over-quantity using exact four-decimal comparisons; cross-GRN allocation is
      serialized by a locked PO row and a cumulative draft/posted receipt query.
- [x] PO and GRN workbench listings filter by the authenticated company before
      pagination and fail closed when no active company is present; newly created
      GRNs inherit the approved PO company for downstream matching and audit reads.

# Release v0.9.1 — Enterprise UI/UX Overhaul

**Release Date:** 2026-05-28

## Overview

Release v0.9.1 is a comprehensive visual and layout upgrade across the **Sales, Procurement, and Inventory** modules. It records the move toward the repository's token-based, dark-mode compatible enterprise UI system.

---

## 🚀 Completed Work

### 1. 📋 Enterprise Form Standardization
All data-entry forms have been rebuilt from generic inputs into a cohesive BEM-lite responsive grid system:
- **Sales Forms**: Customer Form (`customer_form.html`), Quotation Form, Sales Order Form, and Delivery Order Form.
- **Procurement Forms**: PR (Purchase Request), PO (Purchase Order), GRN (Goods Receipt Note), AP Invoice, and AP Payment forms.
- **Inventory Forms**: Stock Adjustment, Stock Transfer, and Stock Take forms.
- **Form Layout Enhancements**:
  - Replaced legacy `.field` with `.form-group` providing predictable spacing.
  - Implemented responsive `.form-grid` (multi-column on desktop, auto-stacking on mobile).
  - Grouped massive forms into `<section class="form-section">` card segments with subtle borders.
  - Implemented `.form-input`, `.form-select`, `.form-label`, and `.form-textarea` classes matching the Midnight Ledger design token library.

### 2. 🔍 Unified Filter Grid Layout
- Added new `.filters-card`, `.filters-grid`, and `.filters-actions` components to `forms.css`.
- Fixed the broken stacked filters on all list views (e.g., Delivery Orders list, Sales Orders list, GRNs list) so they align beautifully in a single, responsive horizontal row on desktop.
- Buttons for filtering and clearing search constraints are styled using consistent `.btn--primary` and `.btn--secondary` variants.

### 3. 📊 Table & List Overhaul
- **Sticky Table Headers**: Applied `.table--sticky` on data tables so headers remain locked at the top of the viewport during long page scrolls.
- **Numerical Parity**: Formatted all financial amounts, quantities, and numeric codes to use monospaced, right-aligned layouts (`.numeric.text-right`) to prevent scanning misalignment.
- **Hover & Truncation**: Standardized hover indicators on row selections and introduced smart truncation (`.truncate.max-w-prose`) to avoid column blowout from lengthy notes or descriptions.

### 4. 🔗 Core CSS Parity
- Audited and updated the main CSS bundle (`web/static/css/components/forms.css`) to align exactly with the utility specifications.
- Validated compile-time template safety (`make build` passing flawlessly).

## 🔮 Future Recommendations & Roadmap

To sustain Odyssey ERP's development velocity and premium user experience, the following initiatives are highly recommended:

### 1. 🐳 Dev Environment Volume Mounting (High Priority)
Currently, static templates and CSS are compiled directly into the binary at build time and run inside Docker without volume mappings. This forces developers to run `docker compose up -d --build app` for every small CSS/HTML change.
- **Action**: Add volume mounts in `docker-compose.yml` for dev mode:
  ```yaml
  app:
    volumes:
      - ./web:/app/web
  ```
- **Benefit**: Local changes in `web/static` and `web/templates` will instantly reflect on browser refresh without restarting or rebuilding containers.

### 2. ⚡ HTMX Progressive Form Interactions
Form submission and dynamic lines currently require full-page reloads or custom manual JS.
- **Action**: Integrate HTMX (`hx-post`, `hx-target`) for inline form validation and dynamic adding/removing of line items (e.g., adding line items in Quotations/Orders).
- **Benefit**: Smooth, single-page application (SPA) feeling with minimal javascript overhead.

### 3. 🌙 Dark Mode KPI Contrast Audit
- **Action**: Adjust the color tokens for background trends and status indicators on the financial dashboards inside dark mode.
- **Benefit**: Enhances accessibility and visual contrast in low-light environments.

### 4. 🗂️ Global `.data-list` Rollout
- **Action**: Audit the remaining Detail views (Quotations, Sales Orders, AP Invoices) and ensure they are utilizing the `.data-list` dt/dd grid components instead of ad-hoc custom tables.

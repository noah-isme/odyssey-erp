# Projects and Timesheets

## Current status

**Partial.** The Horizon foundation supports company-scoped projects, tasks, members, timesheets, and FX snapshots. The public project API is documented in [`integrations.md`](integrations.md).

## Supported scope

- Project creation and company isolation.
- Project tasks and members.
- Timesheet persistence with currency/FX snapshot data.
- Idempotent project creation through the public API.

## Gaps

Milestones, Kanban boards, Gantt charts, project budgets, project cost accounting, and resource-capacity allocation are not currently documented as supported.

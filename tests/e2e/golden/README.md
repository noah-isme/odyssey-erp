# Golden Baseline Files\n\nThese directories contain baseline PNG screenshots for visual regression testing.\n\n## Updating Goldens\n\nRun E2E tests with `ODYSSEY_E2E_UPDATE_GOLDEN=1` to create or update baselines:\n\n```bash\nODYSSEY_E2E_URL=http://localhost:8080 \\\nGOTENBERG_URL=http://localhost:3000 \\\nODYSSEY_E2E_UPDATE_GOLDEN=1 \\\ngo test -tags pdf -run TestVisual ./tests/e2e/ -timeout 300s -count=1\n```\n\n## Directory Structure\n\n- `pdf/` — Screenshots of rendered PDF documents\n- `ui/` — Screenshots of web UI pages
